-# Информационная система бронирования ресурсов

Консольное приложение на Python для бронирования организационных ресурсов: аудиторий, ноутбуков, проекторов и другого оборудования.

Проект разработан в рамках учебной практики ПМ.02
«Осуществление интеграции программных модулей».

---

# Возможности системы

## Авторизация и пользователи
- Регистрация пользователей
- Вход в систему
- Автоматическое присвоение ID
- Просмотр пользователей
- Добавление и удаление пользователей

---

## Работа с ресурсами
- Просмотр ресурсов
- Добавление ресурсов
- Удаление ресурсов
- Категории ресурсов
- Быстрое бронирование

---

## Бронирование
- Создание бронирований
- Отмена бронирований
- Проверка доступности ресурсов
- Проверка корректности даты и времени
- Защита от двойного бронирования

---

## Работа с категориями
- Просмотр категорий
- Добавление категорий
- Удаление категорий
- Просмотр ресурсов определенной категории

# Запуск проекта

## 1. Клонирование репозитория

git clone https://github.com/your-username/booking-system.git

---

## 2. Переход в папку проекта

cd booking-system

---

## 3. Запуск приложения

python main.py

---

# Тестовые данные

При первом запуске система автоматически:
- создаёт базу данных;
- добавляет 5 категорий;
- добавляет 10 тестовых ресурсов.

# Проверки в системе

Реализованы проверки:
- корректности даты;
- корректности времени;
- существования ID;
- доступности ресурса;
- корректности ввода данных.
